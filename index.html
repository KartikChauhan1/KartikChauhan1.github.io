Research

Co-authored manuscript, not yet published.

Sentinel IoT: AI-Driven Zero Trust Security for Real-Time IoT Threat Detection and Response

Authors: Pooja Kumari (corresponding), Eshansh Verma, Kartik Chauhan, Aarush Mehrotra, Anant Pundir

Zero Trust ArchitectureAnomaly DetectionIsolation ForestMicroservices Security
IoT devices are too small to run heavy security software. Sentinel IoT combines Zero Trust access control with an unsupervised model that learns normal device behavior from request rate, packet size, CPU usage and connection time, then blocks devices that repeatedly act abnormally.

Evaluated on three simulated device types (thermostat, industrial sensor, camera); attack-mode devices were identified and isolated.
